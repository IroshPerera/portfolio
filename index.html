Language Technology · Maven Package

Sinhala Transliterator

A lightweight Java library I created to help developers transliterate Sinhala script into Latin characters through predefined mapping rules. It supports Sinhala vowels, consonants, diacritics, digits, punctuation, and safe handling of unsupported characters.
